## New authoring workflow

1. Create a lesson with its title, description, and source text; save it.
2. Review the automatic sentence split. Split or join sentences and save the boundaries independently.
3. Generate all missing sentences with one action, or generate an individual sentence before any others. Recorded sentences have Listen and Regenerate actions. A whole-text narration is no longer required or shown.
4. Select learning words and phrases directly from the saved text and enter Armenian translations. This works before audio generation.
5. Import translations by CSV upload or pasted input. Match words/phrases to the source, show repeated occurrences, highlight accepted selections, and report counts skipped for not existing in the text or lacking a translation. Valid rows can proceed when other rows are invalid. Replacing an existing translation remains an explicit preview choice.
6. Prepare vocabulary audio from the original sentence recordings, then publish when sentence timing, translations, and clips are ready.

The old 500-row/occurrence import limit is removed; input-size and translation-size checks remain. Unsaved edits, stale previews, overlapping phrase selections, and concurrent audio jobs retain their protections. Sentence-specific timing failures and uncertain requests are visible and can be regenerated.

See [sentence-first authoring](sentence-first-authoring.md) for the detailed behavior.
